
# 咕咕嘎嘎桌面便利贴

现有网页加上 Electron 桌面入口。主界面右上角“📌 桌面便利贴”可打开独立窗口。

- 小钉子切换普通 / 置顶窗口，保存选择；不会在输入时主动抢焦点。
- 拖动顶部移动，窗口靠近当前显示器左右工作区边缘 20px 内自动收成标签；也可点击“⇥”手动收起。点击企鹅标签展开。
- 便利贴与桌面主界面的备忘录双向同步，按次修订检测并发；冲突时保留当前草稿，用户可合并后保存。
- 关闭并重启后恢复文字、置顶状态和展开位置。点击 × 仅隐藏便利贴；菜单“退出咕咕嘎嘎”退出应用。
- 当前支持同一桌面应用内共享，不代表与浏览器版、手机或 Supabase 跨设备同步。浏览器已有数据不会自动迁入 Electron；任务可使用原有导入导出，备忘录可复制到桌面版一次。
- 置顶针对普通桌面窗口；系统安全桌面和独占全屏不作覆盖承诺。

## 开发与运行

安装 Node.js 24，在仓库根目录执行：

```sh
npm install
npm start
```

验证及 Windows 便携包：

```sh
npm run check
npm test
npm run test:desktop
npm run package:win
```

Windows 包在 dist/gugugaga-win32-x64，运行 Gugugaga.exe。必须保留整个目录，不要只复制 exe。
PR 的 Desktop note 工作流通过后可从该次运行下载 gugugaga-windows-portable 构建产物。当前没有签名或自动更新。

## 数据与权限

文字和窗口设置保存在 Electron userData 下 sticky-note.json，通过临时文件写入并原子替换。
损坏文件不会自动覆盖。窗口关闭前若仍有未保存草稿会阻止关闭，先完成保存或合并。
Node integration 关闭、context isolation 和 sandbox 开启；桥接仅允许固定便利贴操作，并校验发送窗口及主框架 URL；禁用弹窗和导航。
现有网页的天气自动定位、通知权限在桌面版默认拒绝；天气仍可手动选城市。
Supabase 逻辑未在本次重构。删除了原网页公开硬编码的 AI 密钥，并为 AI 入口加入未配置提示；项目所有者仍须撤销旧密钥（历史记录中仍存在），以后通过服务端代理启用 AI。

## 手动验收

1. 便利贴输入中文、换行；主界面备忘录立即更新，反向编辑也同步。
2. 清空后退出重启，保持为空；置顶状态与窗口位置恢复。
3. 置顶后切到 Word / 浏览器，仍可看见便利贴；取消置顶后按普通窗口层级显示。
4. 拖到左右边缘收起，点击展开；在副屏（含负坐标）验证；移除副屏后仍可找到窗口。
5. 两窗口同时编辑时，冲突草稿保留，合并操作保留两份内容。
6. 隐藏后从主界面重新打开；只剩便利贴时隐藏会先打开主界面，避免应用无法找回。
