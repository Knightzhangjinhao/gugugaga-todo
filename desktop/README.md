# 咕咕嘎嘎桌面便利贴 v0.2

基于现有咕咕嘎嘎主界面的独立桌面便利贴，主界面右上角“📌 桌面便利贴”可打开。

## 使用

- 选中文字，用工具栏选择字体、字号、加粗、斜体、删除线、项目列表或编号列表。Ctrl+B 加粗，Ctrl+I 斜体，Ctrl+Shift+X 删除线。Ctrl+Z 撤销。
- 主界面备忘录和便利贴共享格式与文字；旧版纯文本自动迁移。导出/导入备份也保留备忘录格式。
- 拖动顶部靠近当前显示器左/右边缘，显示吸附预览；松手吸附。在 ⚙ 中也可直接选择左侧、右侧或自由摆放。
- 吸附后鼠标移出约 0.8 秒收起成标签，移入标签展开；可在 ⚙ 关闭自动收起。编辑或拖动时暂缓收起。
- 小钉子切换置顶，支持记忆。置顶针对普通窗口，不覆盖系统安全桌面或独占全屏。
- Ctrl+Alt+N 在其他软件中唤出便利贴。若占用则尝试 Ctrl+Alt+Shift+N；实际快捷键显示在 ⚙ 中。主动唤出后不会因为鼠标留在其他软件上方立即收起。
- 系统托盘企鹅图标可找回隐藏窗口，右键可打开主界面或退出。关闭窗口会隐藏到托盘；完全退出请用托盘菜单。
- 支持副屏负坐标，移除副屏或变更分辨率时找回窗口。

## 数据

文字、格式、位置、置顶和吸附设置保存在 Electron userData 下 sticky-note.json。旧版本升级继续使用同一位置；更新程序目录不会清除笔记。
保存失败会保留草稿；双窗口并发修改会提示冲突，可合并两份内容。未保存草稿会阻止关闭，避免内容丢失。
当前为同一桌面应用内同步，浏览器版/手机不会自动共享。浏览器已有任务可导出后导入桌面版。
粘贴和加载的富文本仅保留文字格式白名单，过滤脚本、图片、事件处理器及任意样式。Node integration 关闭，context isolation 和 sandbox 开启，IPC 校验窗口与主框架 URL。
原项目公开的 AI 密钥已从新版本移除，旧密钥仍需所有者撤销；AI 暂未启用，后续应通过服务端代理恢复。

## 开发与验证

安装 Node.js 24，在仓库根目录运行：

```sh
npm install
npm start
npm run check
npm test
npm run test:desktop
npm run package:win
```

Windows 便携包在 dist/gugugaga-win32-x64，运行 Gugugaga.exe；保留整个目录。
Desktop note 工作流提供 Windows 自动测试及便携构建产物，目前未签名、无自动更新。
测试覆盖旧笔记迁移、格式持久化、并发修订保护、多屏坐标、真实双窗口格式同步、格式工具栏、危险粘贴过滤、原生置顶、贴边/悬停及全局快捷键注册。
可设置 GUGU_SCREENSHOT_DIR 输出自有应用测试窗口的截图，用于视觉检查。

## 手动验收

1. 写中文、换行，加粗/斜体/删除线、改字体和字号；主界面双向同步；退出再开仍保留格式。
2. 拖到两侧，确认预览、吸附、移出收起和移入展开；关闭自动收起后保持展开；自由摆放可脱离边缘。
3. 切到其他软件按快捷键，双击托盘恢复；取消置顶后符合普通窗口层级。
4. 副屏、不同缩放、拔插显示器下窗口可找到；文字选择与拖动不误收起。
5. 导出、清空、导入，备忘录文字与格式恢复；双窗口同时编辑时冲突草稿不丢失。
